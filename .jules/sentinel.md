## 2024-05-18 - Path Traversal Vulnerability in Filename Construction
**Vulnerability:** The `juniper_crawler.py` script constructs output log file names using `ip` and `hostname` values extracted from untrusted network device outputs. These values are used directly within `os.path.join` calls without prior sanitization, creating a path traversal vulnerability. An attacker controlling a network device could provide a maliciously crafted hostname (e.g., `../../../etc/passwd`) or IP string, allowing them to write backup or log files outside of the intended directory and potentially overwrite critical system files.
**Learning:** Network device outputs (like hostnames or CLI command results) should never be trusted as safe inputs for file system operations. Even if the expected input is an IP address or a simple string, it must be treated as untrusted user input because a compromised or misconfigured device can return arbitrary strings.
**Prevention:** Always explicitly sanitize all variables derived from device outputs before using them to construct file paths. Use regular expressions to restrict the input strictly to safe, alphanumeric characters (plus necessary separators like dots or hyphens) to ensure path traversal sequences like `../` cannot be injected.
